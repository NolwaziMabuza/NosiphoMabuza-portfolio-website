Problem

Users needed an online platform where they could browse products and place orders, while administrators needed a structured way to manage store content and order-related information.

Solution

Dragon Stone was built as a PHP and MySQL website with front-end pages for users and admin-side functionality for managing products, categories, users, and order-related data.

Key features

Product browsing

Users can view products and product-related information.

User accounts

Registration and login flows support personalised user access.

Cart and orders

The system supports order-related workflows and customer actions.

Admin CRUD

Admin-side management allows products, categories, users, and order data to be maintained.
