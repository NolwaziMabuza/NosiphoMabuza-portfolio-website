# Nosipho Mabuza Portfolio Website

This is a static portfolio website. It uses HTML, CSS, and JavaScript only.

## How to preview
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click `index.html`.

## Main files to edit
- `index.html` - homepage, about, projects, skills, modules, CV links, and contact details.
- `dragonstone.html` - Dragon Stone case study.
- `grade-a-media.html` - Grade A Media case study.
- `assets/css/styles.css` - website colours, layout, spacing, and responsiveness.

## Photos
The main profile photo is saved as:
- `assets/img/profile-main.jpg`

Additional photo options are saved in:
- `assets/img/profile-options/`

To change the main photo, replace `profile-main.jpg` with another photo or edit this line in `index.html`:

```html
<img src="assets/img/profile-main.jpg" alt="Professional portrait of Nosipho Mabuza" class="profile-img" />
```


## Grade A Media walkthrough videos

The Grade A Media case study includes walkthrough videos inside `assets/videos/`. They are shown on `grade-a-media.html` in the Project Evidence section. Keep the video file names the same unless you also update the matching `<source src="...">` paths in `grade-a-media.html`.

Included videos:
- Login walkthrough
- Browse and search walkthrough
- Cart walkthrough
- Checkout walkthrough
- Full system walkthrough

Because the videos are large, the website ZIP file is much bigger than the earlier version. When publishing online, upload the full folder so the video paths do not break.

VIDEO NOTE
The Grade A Media walkthrough videos in this version were compressed so the ZIP can download/upload more reliably.
