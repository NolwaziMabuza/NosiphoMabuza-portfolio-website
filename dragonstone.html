Dragon Stone E-Commerce Website

A full-stack e-commerce website built for sustainable home, personal care and lifestyle products. The website includes product browsing, user account flows, cart, checkout, demo payment, order confirmation, admin CRUD features and MySQL database integration.

Problem

Customers needed one online place to browse sustainable products and place orders, while administrators needed a structured way to manage products, users, orders and store content instead of relying on manual updates.

Solution

Dragon Stone was built as a PHP and MySQL e-commerce website with customer-facing pages and admin-side management tools. The customer side supports browsing, product details, cart actions, checkout, demo payment and order confirmation. The admin side supports store management through dashboard views, product CRUD features, order tracking, user information and forum moderation.

Key features

Product browsing

Users can browse categories, view products, check prices and add items to the cart.

Cart and checkout

The website supports cart review, quantity updates, delivery details, order summary and checkout flow.

Demo payment and order confirmation

The payment flow is clearly marked as demo-only and leads to an order confirmation page with order details.

Admin dashboard

Admins can view store activity such as orders, users, products and forum posts from the dashboard.

Admin CRUD

Admin-side management allows products and store data to be added, edited and deleted.

Forum and sustainability features

The website includes forum-related features, Eco Points and sustainability-focused content for the store concept.

My contribution

I handled the main build of the Dragon Stone website, including the website structure, user-facing pages, product/category browsing, cart and checkout flow, demo payment pages, order confirmation, admin dashboard, product management, forum/admin features and project debugging.

I also worked on the database-driven functionality using PHP and MySQL, connected the front-end screens to back-end logic, fixed errors during testing and hosted the website so it could be viewed online.

What I learned

This project strengthened my understanding of full-stack web development, database-driven systems, PHP/MySQL integration, CRUD operations, user flows, validation, debugging, hosting and how to present a web application professionally.
