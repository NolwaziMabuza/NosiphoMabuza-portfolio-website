# Nosipho Mabuza Portfolio Website

Responsive portfolio website for Nosipho Nolwazi Mabuza.

## Main files

- `index.html` - homepage
- `dragonstone.html` - Dragon Stone case study
- `grade-a-media.html` - Grade A Media case study
- `portfolio-website.html` - Portfolio Website case study
- `assets/css/styles.css` - website styling
- `assets/cv/Nosipho_Mabuza_Developer_CV.pdf` - single CV for South African and international applications
