Software Engineering Portfolio Website

A responsive personal portfolio website created to present my software engineering profile, selected projects, technical skills, academic strengths, CV documents and professional contact links in one polished place.

Problem

I needed a professional website that could present my work clearly to recruiters, companies and potential collaborators. A CV alone does not always show the full picture, so the website gives more detail about my projects, skills and career direction.

Solution

I created a static portfolio website using HTML, CSS and JavaScript. The website does not need XAMPP because it does not use PHP or a database. It can be opened directly in a browser and can later be hosted using GitHub Pages, Netlify or Vercel.

The design uses a soft baby pink, white and charcoal colour palette to keep the website professional while still matching my personal style.

Key features

Responsive layout

The website is designed to work on desktop, tablet and mobile screen sizes.

Project case studies

Each main project has its own page with the problem, solution, tools used, features and evidence.

Professional positioning

The content is written to support junior software developer, graduate software engineering, web, mobile and QA opportunities.

CV downloads

The website includes buttons for downloading South African and international CV versions.

Contact section

The contact section includes email, phone, LinkedIn, GitHub and a form that opens an email draft.

Simple deployment

The website can be hosted without XAMPP because it is built as a static website.

My contribution

I planned the website structure, organised the content, added my project case studies, linked my CV documents, added contact details and worked on the visual direction of the website.

I also customised the website content to better match the type of roles I am targeting, including software development, graduate software engineering, mobile app development, web development, QA testing and systems analysis.

What I learned

This project helped me practise presenting technical work professionally. I also improved my understanding of responsive layouts, website structure, project storytelling, personal branding and how to make a portfolio feel credible for job applications.

Project note

This website is now linked to its GitHub repository and live GitHub Pages version. It will continue to improve as I add more screenshots, walkthrough videos and future software projects.
